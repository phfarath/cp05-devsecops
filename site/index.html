CP05: um site em contêiner com verificações automáticas de segredos, código e vulnerabilidades da imagem.

01

Gitleaks

Procura segredos no histórico de commits da branch.

02

Semgrep

Analisa o JavaScript e identifica chamadas à função eval.

03

Trivy

Verifica os componentes da imagem Docker em busca de CVEs críticos.

Um push ou pull request inicia os três jobs no GitHub Actions. Um achado de segurança reprova a verificação correspondente. Os resultados reais ficam na aba Actions do repositório.
